# 006 — CLI (Python)

Entry points: `ptx` console script and `python -m pytorch_transformers`.

## Commands

| command | purpose | key flags |
|---|---|---|
| `train-tokenizer` | train + save `tokenizer.json` | `--config`, `--vocab-size`, `--out` |
| `prepare-data` | normalize, filter, dedup, mix, export | `--config`, `--out`, `--max-examples`, `--jesc-official <path>` |
| `train` | train a direction | `--config`, `--direction`, `--resume`, `--device`, `--amp`, `--wandb` |
| `eval` | BLEU/chrF/PPL | `--checkpoint`, `--split`, `--beam`, `--limit`, `--device` |
| `translate` | interactive/file translation | `--checkpoint`, `--text`, `--file`, `--direction`, `--beam` |
| `export` | safetensors + config for Rust | `--checkpoint`, `--out` |
| `bench` | Python vs Rust comparison | `--checkpoint`, `--device`, `--reps`, `--warmup` |

## Requirements

- **FR-CLI-1** Global flags: `--config`, `--device auto|cuda|cpu|mps`, `--seed`,
  `--log-level`.
- **FR-CLI-2** `translate` reads positional text, `--file`, or stdin; supports batch lists.
- **FR-CLI-3** Errors are actionable and non-zero exit: missing checkpoint, tokenizer-hash
  mismatch, direction mismatch, empty input.
- **FR-CLI-4** `--json` on `eval`/`bench` emits machine-readable output for the comparison
  script.

## Acceptance

- `ptx --help` and every subcommand `--help` work.
- A full smoke path works: `prepare-data` (tiny) → `train` (few steps) → `translate`.
